# TMDSCNCD28388D - F28388D controlCARD (TI)
180-pin HSEC8 edge-card controlCARD carrying the TMS320F28388D: the controller our CTRL-C2000 board is built around (D-004).
- **Facts** (SPRUIL8B, May 2020; PCB rev B as of 29 May 2020): 180-pin HSEC8 connector (100-pin DIMM only via the separate TMDSADAP180TO100 adapter); default 25 MHz clock (cards MCU063B and later need C2000Ware >= 3.02, older cards use 20 MHz); on-board isolated XDS100v2 JTAG; micro-USB J3 is NOT isolated from board ground; SCI boot uses GPIO28/29.
- **Informs:** CTRL-C2000 connector/pin plan, clocking, boot and emulation arrangement (ECO-01/02).
- **Limitation:** evaluation card ("not intended to be a complete customer design"); compliance is the system designer's job. No other design in this library targets F28388D (they use F280039/F280039C, F28379D, F2803x), so reference firmware must be ported.
