# Documentation style guide

Every page under `README.md`, `docs/README.md` and `docs/guide/` follows this guide, so the set reads as one document.
It is written for GitHub's renderer (GitHub-flavoured Markdown, Mermaid, alerts, inline HTML — no CSS, no scripts).

## Voice

- Plain engineering English. No marketing words ("revolutionary", "best-in-class", "cutting-edge"), no superlatives.
- **Honesty boundary, always visible:** nothing in this project is bench-validated. Say *calculated*, *simulated* or
  *estimated* next to the number it applies to; never present a calculated figure as measured or a competitor's
  published figure as verified. Open risks are stated, not hidden.
- Every number names its source file (a link) — a report, a spec JSON, a build output. Numbers are dated
  "as of 2026-10-05" where they will move.
- One idea per paragraph; lists and tables over long prose; expand an acronym once per page.

## Page skeleton

```
<!-- breadcrumb -->   [Home](../../README.md) › [Documentation](../README.md) › Page title
# Icon + Title
> one-sentence summary of what the page answers
badges (only where they carry information: status, revision, date)
---
## sections ...
---
<!-- footer -->   ← previous page · [Documentation index](../README.md) · next page →
```

## Visual elements — use each where it helps, not everywhere

| Element | Use for | Rule |
|---|---|---|
| Badges (`img.shields.io/badge/...?style=flat-square`) | status, stage, key figure at the top of a page | at most one row of 4–6; colours from the palette below |
| GitHub alerts `> [!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]`, `[!CAUTION]` | honesty boundary, a risk, a rule the reader must not miss | at most 2–3 per page |
| Mermaid diagrams | block diagrams, flows, state machines, sequences, timelines | ≤ 20 nodes; start with the init block below; label edges |
| Charts (PNG from `docs/assets/figures_*.py`) | comparisons and breakdowns of numbers that exist in a data file | generated by script from repo data, never drawn by hand; `<img width="820">`; caption with the source |
| Tables | specifications, comparisons, traceability | right-align numbers; units in the header |
| `<details><summary>` | long reference material a first reader can skip | summary says what is inside |
| Section icons (emoji) | one per H2 at most, from this set: ⚡ power · 🧭 architecture · 🛡️ protection · 🎛️ control · 🧲 magnetics · 💰 cost · 🔬 verification · 📚 library · 🗺️ roadmap · ⚠️ risk · 🧰 tooling · 📐 specification | no decorative emoji in body text |
| Animated SVG | the banner on the two landing pages only | subtle, loops slowly, honours `prefers-reduced-motion` |

## Palette

| Role | Hex |
|---|---|
| Navy (primary, text on light) | `#0B1F33` |
| Teal (accent, "ours") | `#00A99D` |
| Amber (attention, estimate) | `#F2A007` |
| Coral (risk, competitor contrast) | `#E4572E` |
| Slate (secondary) | `#5B6B7A` |
| Mist (backgrounds) | `#EEF3F7` |

Badge colours: status ok `00A99D`, in progress `F2A007`, open risk `E4572E`, neutral `5B6B7A`, primary `0B1F33`.

## Mermaid init block (first line of every diagram)

```
%%{init: {"theme": "base", "themeVariables": {"primaryColor": "#EEF3F7", "primaryBorderColor": "#0B1F33", "primaryTextColor": "#0B1F33", "lineColor": "#5B6B7A", "secondaryColor": "#D9F2EF", "tertiaryColor": "#FFF4D6", "fontFamily": "Inter, Helvetica, Arial, sans-serif"}}}%%
```

Class conventions inside diagrams: `classDef live fill:#FDE7E0,stroke:#E4572E,color:#0B1F33` (hazardous-live),
`classDef selv fill:#D9F2EF,stroke:#00A99D,color:#0B1F33` (safe side), `classDef ext fill:#FFFFFF,stroke:#5B6B7A,stroke-dasharray:4 3`.

## Charts

`docs/assets/style.py` sets the Matplotlib style (palette, fonts, no top/right spines, 200 dpi, white background) and
provides `save(fig, name, source)` which writes `docs/assets/img/<name>.png` with a small "source · calculated, not
measured" footer. Every figure function reads its numbers from a file in the repository at run time.
