# Megarevo MPHV 1500 V string PCS (145–250 kW)

Datasheet V1.1, link supplied by the owner on 2026-10-04. It is an AC/DC product (three-level string PCS, IP66,
≤ 100 kg, 99 % maximum efficiency, DC contactor + soft-start, DC and AC EMI filters, LCL filter, AC relay, type II DC
surge protection, Ethernet / RS-485 / CAN) — not a DC/DC module — and is on file as the **price benchmark**:

That figure, not the marketplace listings in `gen/data/market_prices.csv` (22–74 USD/kW), is the cost level this
project has to be measured against. See `docs/requirements/COST-REVIEW.md`.
